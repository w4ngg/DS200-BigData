#### This repository contains Big Data lab exercises using Apache Pig, Spark RDD, and Spark DataFrame APIs to process, transform, and analyze large-scale datasets.

#### It also includes a real-time people-counting data pipeline where video frames are streamed through Kafka, stored in MinIO, processed for object detection, and saved as structured results. MongoDB Atlas is used as the cloud database layer to store detection outputs, metadata, and pipeline results for later querying and analysis.
